## 0. 可投资宇宙口径（全局硬规则 · 白名单）

**用户定调：「我只做主板和创业板。」**
可投资宇宙采用**白名单**（比黑名单剔漏更干净）：

| 板块 | 代码前缀 | 是否纳入 |
|---|---|---|
| 沪市主板 | 600 / 601 / 603 / 605 | ✅ |
| 深市主板 | 000 / 001 / 002 / 003 | ✅ |
| 创业板 | 300 / 301 | ✅ |
| 科创板 | 688 / 689 | ❌ |
| 北交所 | 4xxxxx / 8xxxxx（83/87/88 等）/ 920（bj） | ❌ |
| ST 类 | 名称含 `ST`、`*ST`、`退`（即便代码在白名单段） | ❌ |

**作用边界（用户两次强调"对大盘/板块无效"）：**
- 大盘指数（上证/创业板/沪深300…）的点位、K线、MA/MACD/RSI：**不套用此宇宙，原样保留**
  （指数成分由交易所定；创业板指等照常用）。
- 行业/概念板块的资金流、板块涨跌家数、close_scan 主线打分：**不剔除，原样保留**
  （板块是聚合体，不是个股，没有 ST/科创板属性）。
- **逐只个股的统计与情绪池**才套用此白名单，包括：
  - 全A涨跌家数（阶段0 新增）
  - **涨停 / 跌停 / 炸板 / 连板情绪三池**（Q14 已定：一并不再含科创/北交/ST；
    池内若返回这些标的，逐只按白名单+名称过滤后再计数）
  - 以后任何逐只个股的赚钱效应/涨跌统计
- `stock_pool` / 板块领涨龙头的选股逻辑**本次不改**（沿用既有；以后要统一为白名单需另拍板）。

实现：纯函数 `src/universe.js`：`isBoardAllowed(code)`（白名单前缀）/
`isStName(name)` / `inTradableUniverse({code,name})`，配 `jarvis-universe.test.js`
覆盖 600/601/603/605/000/001/002/003/300/301 纳入，688/689/430/830/870/920 排除，
及 ST/*ST/退 名称排除。东财逐只统计尽量用 fs 市场参数先圈范围再名称剔 ST。
所有逐只个股口径的模型工具描述都要写明"仅限主板+创业板，已剔科创/北交/ST"。

> 两市**成交额**取指数/交易所总量，属"大盘量能"，不逐只过滤，默认**不剔**；
> 若实现时改成逐只累加，则按白名单过滤——以实际取数方式在代码注明。

## 1. 引擎 A：缠论生命阶段（结构 / 多级别递归）

### 1.1 范围
- 标的：**仅上证指数 000001**（创业板以后再加）。
- 级别：**30 分 / 60 分 / 日线** 三级。
  - 30/60 分同花顺可回 2023（历史厚，可回测验证）；日线腾讯不封 IP。
  - 5/15 分无长历史源（东财约 7 个月、新浪 1023 根、同花顺无此周期），
    **第一版不做**，上线后自攒，攒厚且三级验证有效再"区间套"往下套。
- 数据复用 `src/tools/stock_kline.js` 的 `kline(code,period)`，不重写抓取；
  另给指数分钟降级链补**腾讯 mkline 备胎**（已实测 5/15/30/60 各 320 根可达）。
- 新增分钟K持久化表（照抄 alert_samples 的 UPSERT+slot+raw 模式），每日自攒。

### 1.2 缠论定义（2026-09-13 用户对图后按"方案A"修订：笔中枢口径）
1. **K线包含处理**：按当前方向合并相邻包含K线（向上取高高、向下取低低）。
2. **分型**：三处理后K，中间高点最高=顶分型；中间低点最低=底分型。
3. **笔**：相邻一顶一底分型，中间独立K（含分型K）**≥5 根** 才成笔（新笔标准）。
4. **中枢按【笔中枢】画（用户选A）**：连续三笔的价格重叠区，
   `ZG=min(各笔高点)`、`ZD=max(各笔低点)`，要求 ZG>ZD。**线段仍计算**（特征序列
   工程化近似）但只用于连大方向，不画主图中枢（用户指标 DLL 口径含线段，主图中枢观感为多个细带）。
5. **走势类型**：笔中枢依次**下移=下跌趋势**、**上移=上涨趋势**、单一中枢反复=**盘整**。
6. **背驰看 MACD 柱衰竭**（智能MACD 12/26/9，柱=2(DIF-DEA)）：相邻两个同类型笔端点，
   价创新高/新低但对应红/绿柱簇峰值变小=顶/底背驰（与"最近一个同类型笔端点"比，
   非跨级别比；此基准待用户对图最终确认）。
7. **三类买卖点（笔级别）**：一买/一卖=末端底/顶背驰；二买/二卖=一买/卖后回踩不创新低/
   反弹不创新高；三买/三卖=顺向笔脱离中枢≥0.6%后回抽不破上沿/反弹不过下沿。
8. **只在 bar 收盘后确认**；盘中未完成K不进结论（防分型被最后一根吃掉而闪烁）。

### 1.3 多级别裁决（区间套思想，先大后小）
- **大级别定方向，小级别找时机**：日线/60分定"能不能多"，30分找具体转折。
- 小级别逆势信号被大级别否决（日线下跌趋势里，30分一个底分型不喊动手）。

### 1.4 阶段呈现（大白话 + 可点开的证据链）
六阶段：**退潮期 / 磨底期 / 筑底期 / 启动期 / 主升期 / 高位震荡期**。
每个标签必须挂结构化依据：
`{级别, 走势类型, 中枢[ZD,ZG], 当前位置: 上沿/下沿/离开段, 笔序号}`。
阶段到六态的精确映射在 chan.js 内以规则函数实现并单测，不靠模型自由发挥。

## 2. 引擎 B：散户崩溃冰点（情绪 / 反向）

### 2.1 第一版三料（零新增数据源，来自现有三池+指数技术面；情绪池已按 §0 白名单过滤）
1. **跌停家数** ≥ 历史高分位（恐慌宣泄）
2. **炸板率** ≥ 历史高分位（资金不敢封板）
3. **连板高度断层**（最高板≤1，或高板≥3 家数=0）

> 三池计数前先过 §0 白名单（只留主板+创业板、剔 ST）；
> 炸板率 = 炸板 /(涨停封板+炸板) 分子分母同口径过滤。

≥2 项进入极端区 = **崩溃共振**；再用 **上证 RSI14 极低 / 显著低于 MA20** 做超跌确认。
（涨停家数冰点、封板资金枯竭先采集、不进第一版触发，观察相关性后再定。）

### 2.2 两级提示
- **普通冰点**：必须缠论阶段处于 **下跌末端 / 磨底期** 才放行（阶段当上下文开关），
  避免"刚开始跌、第一天恐慌就接飞刀"。
- **极端恐慌（左侧越级）**：三料全中 + 各项 ≥95% 分位 + RSI 极端超卖时，
  即使缠论未确认也提示，但强标 **"左侧 · 未标定 · 情绪极值"**，与右侧（缠论确认）区分。

### 2.3 有效性裁判
- 文献/情绪交易书籍只用于**筛选候选指标**，不作为成立依据。
- 最终裁判是 **alert_samples 的 fwd_d1/fwd_d3 前向收益**：
  冰点触发后上证次日/3日是否反转，写 `evaluateFear()` 统计胜率，无效就砍。

## 3. 节奏与标定
- **缠论盘后跑**（收盘K走完才确认）；跑准+前向验证后再放盘中关键时点。
- **崩溃指标盘中算**（恐慌是日内事）。两者刷新节奏分开。
- 阈值先给保守临时值并强制未标定；攒够 **15–20 个交易日**真实分布、
  且前向验证有效，才转正。
- 零新增依赖（不引 mootdx/Python）。任何子源失败 → 置 null+error，绝不拿 null 当 0。
