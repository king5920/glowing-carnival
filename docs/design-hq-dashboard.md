> 效果图：`_mockup/hq-dashboard-v2.html`
> 原市场座舱：`_mockup/hq-dashboard.html`

---

## 一、设计目标

把 JARVIS 46 个工具 + 9 套 429 项测试 + Phase 0-36 的迭代中积累的所有**可观测维度**，统一到一个全屏作战座舱。核心不是"加个仪表盘"，而是让**大盘结构、板块方向、个股信号、AI 性能、记忆演化、语音交互、飞书推送**在同一个画面里可交互联动。

## 三、与现有 JARVIS 的集成

### 3.1 可直接复用的 API（5 个）

| API | 功能 | 用于可视化 |
|---|---|---|
| `/api/market_phase` | 缠论六阶段+崩溃冰点 | 大盘定时机区 |
| `/api/closescan` | 板块+龙头+资金流 | 板块方向+龙头区 |
| `/api/starmap` | 记忆星图节点/边/分类 | KPIs+记忆增长 |
| `/api/tools` | 工具清单+调用日志 | 工具调用Top5 |
| `/api/health/sources` | 数据源健康 | 顶栏健康灯 |

### 3.2 需要新增的后端接口（6 个）

| 新增接口 | 数据源 | 用途 |
|---|---|---|
| `GET /api/indexes` | `stock_kline.kline(code,'day',30)` | 4 指数+sparkline |
| `GET /api/fear_heatmap` | `alert_samples` 表聚合 | 60 日情绪热力图 |
| `GET /api/dragon_tiger` | `dragon_tiger()` 工具 | 龙虎榜+游资席位 |
| `GET /api/sector_trend` | `sector_trend.trend()` | 板块主线评分条 |
| `GET /api/ai_stats` | `llm.getUsage()`+工具调用表 | Token消耗/耗时/成功率 |
| `GET /api/activity` | patrol 冷却表+活动日志 | 巡逻活动时间轴 |

### 3.3 增强现有接口（1 个）

| 接口 | 增强 | 原因 |
|---|---|---|
| `/api/starmap` | 增加 `created_at` 时间戳字段 | 记忆增长趋势 sparkline 需要时间序列 |

## 四、图表类型映射

| 可视化组件 | 图表类型 | 实现方式 |
|---|---|---|
| 缠论阶段圆环 | 弧形进度 | Canvas arc，2/3 共振时画 2/3 弧 |
| 指数 sparkline | 面积折线 | 小 canvas 按行渲染，渐变填充 |
| 情绪热力图 | 竖柱热力 | Canvas 逐日渲染，冷绿→黄→红插值 |
| Token消耗趋势 | 折线图 | Canvas 折线，7 日数据 |
| 工具调用Top5 | 横向条形 | div + width%，零依赖 |
| 响应耗时分布 | 区间条 | div + width%，P50/P90/P99 |
| 板块评分条 | 水平条 | div + width%，连续天数标记 |
| 龙虎榜列表 | 数据表格 | HTML table + 分类标签 |
| 巡逻时间轴 | 滚动标签条 | CSS 动画无限滚动 |
| TAPE滚动 | 滚动文本流 | CSS `@keyframes scroll` |

## 五、设计语言

| 属性 | 值 | 说明 |
|---|---|---|
| 背景 | `#070b11` 深海蓝 | 与现有 UI 一致 |
| 面板 | `rgba(16,24,36,.66)` 毛玻璃 | `backdrop-filter:blur(10px)` |

| 涨跌色 | `#f23645` 红涨 `#089981` 绿跌 | **唯一高饱和色**，只表行情 |
| 数字 | `"SF Mono",Consolas` 等宽 | `tabular-nums lining-nums` |

| 扫描线 | `rgba(255,255,255,.013)` 1px | 氛围层，不干扰 |

## 六、数据诚实原则

1. **未标定处统一挂"观察"标签**：`结构/阈值未标定 · 仅供观察 · 非买入建议`
2. **无数据时显示"待接/示例"占位**，不编造数字
3. **示意数据明确标注**：如"示意"、"示例回放"、"待接入"
4. **所有 KPI 来自真实 API**，无硬编码假值
5. **颜色只表达语义**：红涨绿跌外，其余全部中性冷蓝

## 九、约束与风险

| 约束 | 风险 | 应对 |
|---|---|---|
| 生产依赖仅 `better-sqlite3` | 图表必须零依赖纯 Canvas | 与现有 starfield.js/voicecore.js 同模式 |
| Node ≥ 25.x ABI 141 | 不能引 node-canvas 等原生模块 | 全部前端渲染，后端只给 JSON |
| 飞书推送已限频 | 不能把推送历史当数据源全量拉 | 只统计聚合值，不拉明细 |
| 未标定信号 | 模型可能误读为建议 | 统一"观察"标签 + 输出前缀声明 |
| Token 消耗 | 7 日数据需持久化，内存易丢 | SQLite 消息表已有 created_at，需加聚合索引 |
